# Changelog

## 1.0.0

First release.

- The color schemes of Vim 9.2 as 34 themes for VS Code and VSCodium.
- Syntax colors with Vim's own syntax rules for 87 languages and formats. Vim does not need to
  be installed, and no language extensions are needed.
- The file type is detected as in Vim, from the file name and sometimes the content.
- Background colors for the Vim groups `Todo`, `Error` and `Constant` (setting
  `vimsem.backgroundGroups`).
- Editor colors from the color scheme (line numbers, cursor line, cursor, selection, search
  matches). Side bar, tabs and status bar are derived from the same colors.

Known limitations are listed in the README.
